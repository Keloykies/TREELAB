What is an AVL Tree?

Purpose & structure

An AVL Tree is a Binary Search Tree that automatically keeps its height balanced after insertions and deletions. For every node, the heights of its left and right subtrees can differ by at most 1.

Why use it?
Keeping the tree balanced helps search, insertion, and deletion stay efficient: typically O(log n).
Operation guide

Balance Factor & rotations

Balance Factor = height(left) − height(right). A node is balanced when its factor is −1, 0, or +1.

LL → Right rotation RR → Left rotation LR → Left, then right RL → Right, then left

What is a B-Tree?

Purpose & structure

A B-Tree is a self-balancing search tree in which one node can store multiple sorted keys and have multiple children. All leaf nodes stay at the same depth.

Why use it?
B-Trees reduce the number of levels visited when working with large datasets. They are widely used in databases and file systems.
How this example works

Minimum degree t = 2

With t = 2, each node can hold at most 3 keys and have at most 4 children (except that the root has special minimum rules). When a full node must receive another key, it splits and its middle key moves up to the parent.
